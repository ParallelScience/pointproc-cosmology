**Title: Disentangling Satellite Radial Profiles via Mass-Conditioned Stochastic Modeling**

This study isolates the HOD's satellite placement logic by performing a conditional radial profile analysis, $n(r|M_{vir})$, using host halo mass as a direct diagnostic variable. By leveraging the `halo_catalog` to partition galaxies into mass bins—specifically targeting halos above $M_{sat} = 10^{13} M_\odot/h$—we will extract the empirical satellite density profiles and compare them against the theoretical exponential decay $e^{-r/R_{vir}}$. We will replace global summary statistics with a likelihood-based comparison, fitting the observed satellite coordinates to a Neyman-Scott kernel model where the scale parameter is treated as a free variable to quantify deviations from the input HOD. By computing the marked correlation function specifically within the 1-halo regime ($r < 5$ Mpc/h), we will test whether the luminosity offset (0.5 dex) correlates with spatial dispersion within the halo. This approach effectively disentangles the 1-halo satellite distribution from the 2-halo halo-halo clustering, providing a rigorous metric for validating the HOD's spatial implementation against the underlying halo mass function.
